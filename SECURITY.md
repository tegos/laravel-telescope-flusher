# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.x     | Yes       |

## Reporting a Vulnerability

Please do not report security issues through public GitHub issues.

Email **tegosiv@gmail.com** with a description of the issue and steps to reproduce. You will get a reply within 7 days. Once a fix is released, the issue will be disclosed in the release notes.
